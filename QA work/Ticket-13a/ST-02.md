# ST-02 - Safe Retry Mechanism & Idempotent Request Token Handling

## Information
- Ticket ID: [Ticket ID] / ST-02 (Safe Retry Mechanism & Idempotent Request Token Handling)
- Assigned developer: [Developer Name]
- Current QA status: Pass

## Objective
- Verify that failed requests render a `"Try again"` button, generate one unique `request_token` per new user action, reuse the exact same `request_token` across retries, disable the retry button while a request is in progress, and send only one request when tapped 5 times rapidly.

## Acceptance Criteria
- [x] Every failed request shows a “Try again” button.
- [x] The browser creates one unique request token per action and reuses the same token on retry.
- [x] Tapping retry 5 times quickly sends the action once.
- [x] The retry button is disabled while a request is in progress.

| TC-03 | Tap `"Try again"` 5 times rapidly while disabled | Button sets `disabled=true` immediately on first tap and triggers only one retry request | Pass |

#### Steps to Reproduce
1. Trigger multiple new actions via `.start()` and inspect the generated `token` values in the QA Event Log.
2. Trigger a failed request and click `"Try again"` once; compare the retry `token` against the initial failed `token`.
3. Trigger a failed request and run **Auto-Tap Retry 5x** (5 synchronous `.click()` calls on `.lc-retry-btn`).

#### Expected Result
- Every new action generates a unique UUID token.
- Retrying a failed action reuses the exact same token.
- Rapidly tapping `"Try again"` 5 times disables the button immediately (`disabled=true`) and sends only a single retry request.

#### Actual Result
- Fresh `.start()` runs generated distinct UUIDs (`22d0b0d8-91eb-409d-ac50-76987fe2c8a0`, `f22e5595-f110-430e-a104-8b87737d1443`, `67a81d7c-5906-4a88-86f9-be1f99d79825`, `a3b9c935-7aa8-41ee-9f9f-c672199914de`, `5d4274ab-8767-49da-8307-4305f19a8fbf`)[cite: 3].
- Retry runs reused the exact active token (`67a81d7c-5906-4a88-86f9-be1f99d79825` across `Request #1` at `12:37:22.575` and `Request #2` at `12:37:25.020`)[cite: 3].
- Simulating 5 rapid clicks at `12:37:27.724` logged `disabled=true` for all 5 clicks and triggered only one retry (`Request #4` at `12:37:27.725` with `token=a3b9c935-7aa8-41ee-9f9f-c672199914de`)[cite: 3].

#### Result
TC-01 Pass; TC-02 Pass; TC-03 Pass.
