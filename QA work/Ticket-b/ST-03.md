## Information

- Assigned developer: [Developer Name]
- Current QA status: Pass

## Objective
- Verify that `IdempotencyService.php` creates one attendance record for a new `request_token`, returns the original record (`CLOCK_ALREADY_RECORDED`) without creating duplicate rows on single or 5x rapid retries, blocks cross-user token reuse (`TOKEN_USER_MISMATCH`), and rejects invalid/missing tokens (`INVALID_REQUEST_TOKEN`).

## Acceptance Criteria
- [x] Submitting the same `request_token` repeatedly for the same staff member returns the original record without inserting duplicate rows.
- [x] Five rapid concurrent/sequential requests with the same `request_token` create only one attendance record.
- [x] Cross-user reuse and blank/missing/invalid tokens are rejected without creating rows.
